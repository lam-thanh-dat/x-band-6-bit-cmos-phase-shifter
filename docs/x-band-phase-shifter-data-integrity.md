# Data Integrity Review

## Authoritative Sources

The repository uses the native CSV files exported from Cadence as the
authoritative numerical sources:

| Repository file | Original quantity |
| --- | --- |
| `phase_shifter_s21_phase_deg.csv` | Transmission phase in degrees |
| `phase_shifter_s21_magnitude_db.csv` | Transmission magnitude in dB |
| `phase_shifter_s11_magnitude_db.csv` | Input reflection magnitude in dB |

The analysis verifies that:

- each file contains exactly 64 unique control states;
- the state set maps exactly to indices 0 through 63;
- the three files use identical control combinations;
- each state contains values at 9, 10, and 11 GHz;
- control voltages are either 0 or 1.8 V.

The raw CSV rule in `.gitattributes` disables Git text normalization for
`data/raw/cadence-exports/*.csv`, preserving native CRLF bytes. Byte-level
digests are recorded in `data/raw/SHA256SUMS` and verified by
`scripts/verify_raw_data_checksums.py`.

## Excluded Spreadsheet Issue

The submitted workbook `data_IL.xlsx` contains a formula-reference error:

- the 11 GHz derived column references the 10 GHz source column;
- the per-state average repeats that incorrectly referenced column.

For example, the workbook uses `L=-J` where `L=-I` is required, and its average
duplicates column `L`. This produces an aggregate insertion-loss value of
approximately 15.90 dB instead of the independently recalculated 15.69 dB.

The workbook is therefore not included in the standardized repository. The raw
CSV exports are preserved, and all derived values are regenerated by a tested
Python workflow.

The submitted phase workbook evaluates its displayed RMS formula at 10 GHz
only. The repository workflow extends the same documented definition to all
three available frequency samples.

## NMOS Provenance

The three NMOS `real(Z11)` and `imag(Y11)` samples are transcribed from the
original academic report into
`data/reference/historical_nmos_characterization.csv`. They are not native
Cadence exports. The repository can reproduce the reported resistance,
capacitance, and reactance arithmetic from those values, but not the underlying
device simulation.
