# Data

`raw/cadence-exports/` contains the three unmodified numerical exports used by
the original report. Filenames were changed to describe the measured
S-parameter quantity. The `.gitattributes` rule preserves their native line
endings, and `raw/SHA256SUMS` records their byte-level SHA-256 digests.

`processed/phase_shifter_64_states.csv` is a tidy dataset generated by
`scripts/analyze_phase_shifter.py`. Each row contains one state-frequency
observation, its control bits, ideal and simulated phase, phase error,
insertion loss, and input return loss.

`reference/historical_nmos_characterization.csv` contains three NMOS samples
transcribed from the original report. It is not a native Cadence export.
`processed/nmos_switch_characterization.csv` is regenerated from those
historical samples by `scripts/analyze_nmos_switch.py`.

Do not manually edit processed files. Regenerate them with the documented
scripts.
